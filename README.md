# 护眼提醒

护眼提醒是一个轻量的 macOS 菜单栏应用，使用系统 AppKit 编写，无第三方运行依赖。它默认采用 20-20-20 规则：每工作 20 分钟，看 6 米以外至少 20 秒；每 4 次护眼休息后安排一次 5 分钟长休息。

## 功能

- 菜单栏显示下一次提醒倒计时
- 护眼休息和长休息倒计时窗口
- 暂停、继续、立即休息及推迟 5 分钟
- 自定义工作间隔、休息时长和长休息频率
- 设置保存在本机，不收集或上传数据

## 系统要求

- macOS 13 或更高版本
- 构建源码时需要 Xcode Command Line Tools，可运行 `xcode-select --install` 安装

## 构建并运行

```bash
git clone https://github.com/Allen-LPL/eye-care-reminder.git
cd eye-care-reminder
./run.sh
```

`run.sh` 会在首次运行时构建应用，然后打开 `护眼提醒.app`。程序运行后，菜单栏会出现眼睛图标。

修改源码后，可重新构建：

```bash
./build.sh
```

## 安装

构建完成后，可以把 `护眼提醒.app` 拖入“应用程序”文件夹。若需要开机自动运行，在“系统设置 → 通用 → 登录项”中添加该应用。

## 设置范围

| 设置 | 可选范围 | 默认值 |
| --- | --- | --- |
| 工作间隔 | 1–180 分钟 | 20 分钟 |
| 护眼休息 | 5–300 秒 | 20 秒 |
| 长休息频率 | 每 1–12 次 | 每 4 次 |
| 长休息时长 | 1–30 分钟 | 5 分钟 |

设置通过 macOS `UserDefaults` 保存在本机。

## 项目结构

- `EyeCareReminder.m`：菜单栏、提醒窗口和设置界面
- `Info.plist`：macOS 应用元数据
- `build.sh`：编译并签名本地应用包
- `run.sh`：按需构建并启动应用
